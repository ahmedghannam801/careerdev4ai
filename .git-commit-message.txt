chore: the tool that applies a migration when the cli cannot reach the database

The Supabase CLI opens a direct Postgres connection to apply a migration, and
that connection is IPv6 on this network, where IPv6 is not carried. The
Management API is the way a migration reaches the project from here.

The script applies the file that is in the repository — it decides nothing —
and records the version in the migration history in the shape the CLI uses,
so a later `db push` knows the file has been applied.

The renderer of the PDF samples now waits longer before it takes the
photograph: a file whose pages are pictures takes longer to paint than a
file whose pages are text, and a blank photograph of the document is worse
than no photograph at all.
